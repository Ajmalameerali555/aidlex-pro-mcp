## Reproduce locally

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -o addopts=''
python -m compileall -q aidlex_mcp scripts tests
```

Run the server separately, then:

```bash
python scripts/smoke_test.py
```

On an internet-connected development environment, additionally run the independent official SDK probe:

```bash
python -m pip install -r requirements-interop.txt
python scripts/interop_mcp_sdk.py
```

For a protected profile supply a short-lived `AIDLEX_TEST_ACCESS_TOKEN` securely through the local environment. Validate full OAuth and private-case behavior in ChatGPT before public submission.
