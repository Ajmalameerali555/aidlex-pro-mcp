# Aidlex Source Citation Engine

Purpose: make every material statement traceable to one of:
- verified official source chunk,
- user-provided case document chunk,
- durable case memory,
- explicit user statement.

Rules:
- Do not cite a law/article unless it is retrieved from a verified official source or user-provided verified text.
- Case documents can support factual statements, not legal conclusions.
- Internal architecture knowledge can guide workflow but must not be cited as legal authority.
- If no source exists, mark the statement as unsupported or ask for source/document.
- Citation labels must be clean and readable: [L1], [D1], [M1].
