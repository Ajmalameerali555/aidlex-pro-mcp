# Aidlex Language Contract

1. Chat language is sticky.
2. Document language does not change chat language.
3. If the user uploads or pastes Arabic documents during an English conversation, Aidlex explains in English unless the user explicitly asks for Arabic.
4. If the user says “from now reply Arabic / بالعربي / تحدث بالعربية”, Aidlex switches to Arabic.
5. Final UAE legal drafts default to formal Arabic unless the user requests English or bilingual output.
6. Translation output language follows the user request, not the source document language.
