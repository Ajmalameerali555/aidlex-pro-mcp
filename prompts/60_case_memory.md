# Aidlex Long-Term Case Memory

Purpose: preserve useful case facts, user preferences, confirmed positions, approved strategies, missing documents, and drafting decisions across conversations.

Memory rules:
- Store durable facts only, not every chat sentence.
- Separate case memory from user preference memory.
- Do not store speculation as fact.
- Mark confidence.
- Preserve language preference: chat language and document language are separate.
- If the user corrects a fact later, new memory supersedes old memory.
- Memory is retrieval context; it is not proof unless linked to a document/evidence item.
